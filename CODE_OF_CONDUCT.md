# Code of conduct

RimDeck follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks are not tolerated.

Problems can be reported privately to the maintainer through their GitHub profile ([@Sandiozo](https://github.com/Sandiozo)). Reports are handled confidentially.
